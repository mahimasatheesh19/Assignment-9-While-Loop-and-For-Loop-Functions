# Assignment-9-While-Loop-and-For-Loop-Functions
This assignment contains While Loop and For Loop, Functions in Python
1. First problem is create a number guessing game.
   Main concept of this problem is using While loop, Else statement, Break statement, Continue statement and random.randint().
2. Second problem is about creating a multiplication table generator
   It includes the concepts For loop, Range and Arithmetic operator.
3. Third is create BMI calculator using formula BMI = weight (kg) / [height (m)]2
   Functions, Function parameters and Return statement are concepts used here.
Through this assignment we can understand the while loop and for loop. Using the statements, calling function, arithmetic operations etc...
